# microSD Books 新書未匯入排查（2026-11-17）

## 實際證據

- 使用者新增書籍到 microSD 的 `Books`。
- 排查前 KoboStyle 共 4,117 筆：Books 來源的 4,092 筆皆被標為 unavailable，來源為 reauthorize；其餘為先前合成驗收文件。
- 記憶卡正常掛載，Books 可唯讀列舉。共 15,000 個檔案，其中 EPUB 5,907、PDF 2,234，合計 8,141 本；依文件 ID 比對有 4,049 本 EPUB/PDF 尚未入庫。其他格式不在現有 EPUB/PDF 支援範圍。
- 來源診斷 instrumentation 從 App 身分確認全部四個來源的持續讀取授權有效，查詢成功。Books 根下為 11 個資料夾；測試僅回報筆數及例外類別，不記錄書名／路徑。
- 舊掃描器上限為 10,000 個文件／資料夾；某一子資料夾查詢超出剩餘額度時拋出一般例外，外層把它當作授權失效，將整個來源標為 reauthorize，並把全部既有書籍標為 unavailable。前述 15,000 檔案必定超過舊上限；不是使用者重新授權就能排除的問題。

## 修正

- 將有限遍歷額度提高為 50,000 個文件／資料夾，保留深度 32、取消、重複 ID 防護與 EPUB/PDF 安全解析限制。
- 超限使用獨立例外，來源標為 partial，顯示既有安全上限提示；不執行 markMissing、不清除既有書籍可用狀態。
- 一般 provider 失敗標為 scan_error，提示確認儲存裝置後重掃，保留既有書籍狀態；確實的權限拒絕／文件不存在仍提示來源不可用。
- 對正常且大小、修改時間皆未變更的書籍重用中繼資料；縮圖淘汰不代表書名／作者失效。先前成功產生封面紀錄、卻被整批標為 unavailable 的舊書，須再次開啟唯讀 descriptor 確認可讀，才恢復狀態並重用。已知 metadata_error 或大小／時間變更仍重新解析。此為 metadata 比對快取，不是內容雜湊；provider 不更新時間／大小的同大小內容變動仍有限制。
- 掃描完成提示維持使用者要求的「掃描結束：已處理 X 本」，不重新加入失敗數。
